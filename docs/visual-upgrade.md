# 界面、角色与稳定性升级

基于 `0352798`，2026-10-14。本次是原型视觉升级与缺陷修复，不代表完整游戏已经完成。

## 视觉与交互

- 统一深青、鼠尾草绿、暖金色界面；重做标题场景、状态栏、任务追踪、区域图、底部菜单。
- 背包、装备、技能、阵营改为卡片面板；装备和技能支持点击，也保留原来的快捷键。
- 任务日志支持滚轮；面板互斥，Esc 关闭，面板打开时暂停地表移动与遭遇。
- 生成并预加载全部 46 个敌人 ID 对应的 SVG 贴图，按兽类、鸟类、鹿、傀儡、虫类、幽灵、爬行动物、两栖怪及人形等轮廓与元素配色区分；Boss/精英有额外标记。这些是程序化 2D 外观，不是 3D 模型，也不是 46 套独立逐帧动画。
- 玩家与 NPC 使用旅人、商人、守卫、法师、猎人、村民外观；NPC 对话增加角色立绘。
- 加入树、灌木、石块、房屋、商摊、传送门和地表细节。装饰没有新增碰撞阻挡。
- 战斗增加挥剑弧线、伤害数字、受击闪色、敌人攻击前摇与预警。
- 出生点 (4,4) 加入行旅商人：E 交易，数字键或点击购买；地牢使用同一商店组件。
- 出生点附近加入三组共五只灰烬狼，让第一章有明确、持久化的目标来源；追踪栏显示附近目标方向。
- 地牢地图自适应尺寸，可点击相邻节点移动；右侧显示房间与角色外观。
- 美术运行时全部本地生成，无图片 CDN 或网络依赖。

## 缺陷修复

1. 已访问地点在后续任务接取时补算，不再因提前探索错过 reach 事件。
2. 奖励结算统一补算访问/持有物品，并推进后续主线；重复同步不重复发奖。
3. 读档以装备计算的生命上限校验，支持 135 等大于 100 的合法生命值。
4. 卸装备后按新上限约束生命；地牢休息、战败恢复和 HUD 使用装备生命上限。
5. 存储不可用时不再报告保存成功。
6. 地表场景重入重置技能、声望等面板状态；移除废弃区块纹理。
7. 敌人尊重 Boss/精英与 staggerImmune 的硬直免疫；死亡玩家不再继续执行攻击输入。
8. 在地牢/战斗完成末章后，返回地表也能触发结局。
9. 商店子对象正确使用屏幕空间，修复相机滚动后的点击命中偏移。
10. 关键抉择选择后立即存档。

## 验证

- `npm run typecheck`
- `npm run validate:data`
- `npm test`：223 个测试（含新增 9 个回归用例）
- `npm run build:standalone`
- `python3 scripts/e2e/visual_upgrade_e2e.py`：真实按键移动、交易、金币不足、点击关闭、装备、面板互斥、场景往返、地牢商店、135 HP 存读档。
- `python3 scripts/e2e/main_playthrough_e2e.py`：任务链检查；仍注入击杀与材料，不等同于真实游玩全通关。
- `python3 scripts/e2e/shop_e2e.py`
- `python3 scripts/e2e/standalone_e2e.py`

浏览器脚本需要 Python Playwright 及 Chromium：`pip install playwright && python -m playwright install chromium`。
