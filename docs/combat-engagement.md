# 战斗接敌优化

## 问题

旧遭遇战中玩家出生于 (320,360)，第一名怪物出生于 (820,200)，距离约 525 像素，但普通近战警戒距离只有 330。进入遭遇战后怪物仍按巡逻警戒逻辑等待，导致“已经遇敌，还要再走过去接敌”。普攻又依赖玩家手动调整方向，重复操作多。

## 本轮实现

- 遭遇玩家站位改为 (420,380)，首名敌人 (680,380)，多人采用分散队形，当前地表 1–2 人、地牢 1–3 人均处于战斗场内。
- 敌方有 650 ms 入场缓冲。玩家可先操作，敌人缓冲结束后启动 AI，不在切场景第一帧偷袭。
- 遭遇战内使用覆盖场地的警戒/追击范围，不再要求玩家第二次走进警戒区；试炼仍保留原警戒逻辑。
- 按住 J 且没有 WASD 输入时，自动朝最近存活敌人移动，在武器范围内略留余量停下，再按原伤害/攻击间隔普攻；不在赶路时反复空挥消耗普攻冷却。
- 松开 J 停止追击；WASD 手动走位优先；闪避、冲刺、硬直移动分支优先，不会被自动追击覆盖。
- 按住 J 显示当前自动选择目标的脚下标记；目标死亡后自动选择剩余最近目标。
- 静止、非冲刺/闪避时施放 strike/bolt/blast 技能，辅助转向最近敌人。没有自动施法，没有延长技能射程或绕过资源、冷却与目标判定。
- 更新屏幕提示与 README。

## 边界

本轮保留“地表遇敌→独立即时战斗→结算返回”的结构；不是无缝战斗，也不是挂机自动清场。自动追击目前针对无障碍战斗场，不是通用寻路。未完成全敌人/全装备平衡，也未调整经验与掉落。后续可继续评估目标锁定、群怪挤压、攻击反馈以及是否值得重构为地表无缝战斗，不能只删掉切场景就算完成。
