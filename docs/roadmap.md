## 阶段详情

### 阶段 0：工程搭建

**交付物**
- Vite + Phaser 3 + TypeScript 项目骨架
- `data/` 目录与 JSON 加载器
- `npm run validate:data` 校验脚本（检查 ID 引用、必填字段）
- 基础 ESLint、Prettier、Vitest 配置
- 资源目录与 Git LFS 配置（见 [资源规范](asset-guidelines.md)）

**验收标准**
- `npm run dev` 能打开空白场景
- `npm run validate:data` 对示例数据返回通过
- `npm test` 至少包含一个通过的测试

### 阶段 1：核心玩法原型

**交付物**
- 玩家移动、冲刺、闪避（含无敌帧）
- 普通攻击、重击、远程攻击
- 3 种基础敌人与简单 AI（巡逻、追击、包围）
- 伤害公式与受击硬直

**验收标准**
- 一个可以完整战斗的测试房间
- 伤害公式有单元测试覆盖

### 阶段 2：地牢生成

**交付物**
- 房间图生成器（树形骨架 + 环路补充）
- 房间模板系统，支持战斗、宝箱、事件、Boss、商店、休息点
- 连通性检测与种子重试机制
- 12 层深度的难度参数表

**验收标准**
- 同一种子在多次运行中生成完全一致
- 随机抽取 1000 个种子，连通性检测全部通过

### 阶段 3：开放世界

**交付物**
- 按区块（64×64）按需生成的地形
- 生物群系映射、河流与道路
- 昼夜周期与天气系统
- 地表敌人刷新与资源点

**验收标准**
- 世界可以无缝移动，区块加载不卡顿
- 昼夜与天气对敌人和视野有可见影响

### 阶段 4：成长系统

**交付物**
- 装备品质 6 级，词条池至少 60 种
- 套装系统（2、4、6 件效果）
- 技能树三分支，每个分支不少于 15 个技能
- 组合技机制

**验收标准**
- 装备与技能的数值写在 JSON 中，不需要改代码即可调整
- 技能树重置与转职流程完整可用

### 阶段 5：叙事系统

**交付物**
- 任务状态机（locked、available、active、completed、failed）
- 对话图解释器，支持条件与效果
- 标记系统，所有标记可持久化

**验收标准**
- 任意任务的依赖关系可以通过 `quests.json` 配置
- 对话条件判断的单元测试覆盖主要分支

### 阶段 6：阵营与结局

**交付物**
- 五个阵营的声望系统与档位效果
- 关键抉择分布在第 4、10、16、22 章
- 结局判定器与 `endings.json` 条件表
- 初版 7 个结局

**验收标准**
- 每个结局至少有一条可复现的通关路径
- 声望变化对商店、任务和区域可达性有实际影响

### 阶段 7：内容生产

**交付物**
- 24 章主线，每章平均 1–2 小时
- 约 120 个支线任务，约 20 个隐藏任务
- 约 45 种敌人（含 12 种精英、8 个 Boss）
- 对话节点约 2000 个

**验收标准**
- 主线可以从头到尾通关，无阻断性 Bug
- 内容数量通过 `scripts/` 中的统计脚本核对

**说明**：内容生产可以与阶段 4–6 并行推进，但需要在阶段 7 完成全部数量验收。

### 阶段 8：长线与发布

**交付物**
- 3 个周目系统，包括遗产继承与新词条池
- 无尽深渊模式
- 数值平衡表与模拟脚本
- Tauri 桌面打包（Windows、macOS、Linux）
- 性能优化与多平台测试

**验收标准**
- 一名测试玩家从零开始通关主线的时长落在 40–60 小时区间
- 三个周目全部可以完整通关
- 各平台安装包可以正常启动并存档
