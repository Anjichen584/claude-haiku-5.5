# 设计目标（Design Targets）

> 项目：《裂隙编年史 / Rift Chronicles》
> 版本：v0.1（草案）
> 最后更新：2026-10-14

本文档定义项目的长线体量目标与设计约束。所有内容规模、路线图排期与平衡工作都以此为基准。

---

## 1. 核心体验目标

| 项目 | 目标 |
|---|---|
| 游戏类型 | 2D 开放世界 RPG + Roguelike 地牢 |
| 目标通关时长 | 约 **40–60 小时** 主线 + 支线完成 |
| 每日游玩时长 | 4–6 小时（代表性玩家） |
| 目标完整周期 | 约 **1 个月** 完成一个主结局路线 |
| 完整内容周期 | 全部结局与隐藏内容约 **80–100 小时** |
| 重玩价值 | 至少 3 个周目，每个周目有可感知的差异 |

### 1.1 为什么是这个数字

- 一个月、每天 4–6 小时，约等于 **120–180 小时** 的总投入。
- 长线目标需要留出“探索”和“重复玩法”的空间，因此主线通关定在 40–60 小时，剩余时间留给支线、地牢与周目。
- 这个体量意味着内容必须可程序化扩展，手工内容无法单独支撑。

---

## 2. 体量分配

| 内容模块 | 目标数量 | 估算游玩时长占比 |
|---|---|---|
| 主线章节 | 24 章（原 12 章扩展） | 约 25% |
| 支线任务 | 约 120 个 | 约 25% |
| 隐藏任务 | 约 20 个 | 约 5% |
| 地牢（裂隙） | 12 层深度，每层多种模板 | 约 25% |
| 无尽深渊（后期） | 1 种模式，按层数无限延伸 | 约 10% |
| 周目与遗产系统 | 3 个周目，各自的继承规则 | 约 10% |

---

## 3. 长线设计原则

1. **每个小时都有一个“下一步”**：玩家随时应该知道接下来能做什么，避免无目的徘徊。
2. **成长曲线要长**：角色等级上限约 80，技能树需要至少 3 次大幅转职的机会。
3. **地牢提供短期循环，地表提供长期目标**：每次地牢通关带来即时奖励，主线推进带来长期方向。
4. **选择要有分量**：关键选择至少分布在第 4、10、16、22 章，避免只在结尾决定结局。
5. **周目要有新鲜感**：二周目开放新的装备词条池与敌人变体，三周目开启隐藏结局路线。
6. **数值平衡可回溯**：所有数值写在 JSON 中，便于在不改代码的前提下调整节奏。

---

## 4. 进度与节奏约束

| 阶段 | 大致时长 | 玩家应达到的状态 |
|---|---|---|
| 序章 | 约 2 小时 | 理解核心玩法，完成第一次地牢 |
| 早期 | 约 8 小时 | 确定主要阵营倾向，解锁首个技能分支 |
| 中期 | 约 20 小时 | 完成大部分支线，装备进入史诗品质 |
| 后期 | 约 20 小时 | 面临关键抉择，地牢深度推进到第 8 层以上 |
| 终局 | 约 10 小时 | 进入裂隙核心，结局判定 |
| 周目 | 不限 | 使用遗产重新开始，解锁新内容 |

---

## 5. 内容量化指标（用于排期与验收）

- 每个主线章节平均游玩时长：**1–2 小时**。
- 每个支线任务平均游玩时长：**15–30 分钟**。
- 每层地牢平均通关时长：**15–25 分钟**。
- 对话节点：每章不少于 **80 个**，全游戏约 **2000 个**。
- 装备词条：至少 **60 种**，覆盖 6 个品质。
- 敌人种类：至少 **45 种**，其中精英 **12 种**，Boss **8 个**。

---

## 6. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 内容量超出开发能力 | 进度延期 | 优先保证主线完整，支线按阶段分批交付 |
| 长线玩家后期疲劳 | 流失率高 | 周目、遗产与无尽深渊提供长期目标 |
| 仓库体积膨胀 | 推送变慢，超出 GitHub 限制 | 美术与音频走 Git LFS，源文件放仓库外 |
| 数值失衡 | 某阶段过难或过易 | 建立数值模拟脚本，基于 JSON 快速调整 |
