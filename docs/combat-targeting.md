# 战斗第二轮：目标锁定、群怪间距与预警

## 目标与实现

1. **稳定目标**：进入战斗默认选择最近存活敌人；选定后保持，不因其他怪稍近就跳目标。Tab 按距离顺序循环，点击敌人贴图可直接锁定。死亡或移除后重新选最近存活目标。尸体禁用交互。
2. **统一目标反馈**：顶部显示目标名字和生命，脚下常驻选中标记。J 追击与静止攻击技能辅助朝向共用该锁定目标。
3. **技能有效目标优先**：CombatRuntime.cast 接受可选的目标 id，仅在原有射程和正面角度条件成立时优先选中；没有穿透射程或背向命中的特殊待遇。范围攻击仍按原规则命中多个敌人。
4. **群怪分散**：存活敌人进行软性位置校正，默认中心间距 72 像素。正在蓄力、硬直或眩晕的敌人固定，不会因排斥修改预警位置。两只同时固定时允许临时重叠，解除固定后再分散。
5. **HUD 安全范围**：统一玩家与敌人活动边界为 x=110..1170、y=210..500，避免进入技能栏区域；同步调整试炼的猎犬出生点。
6. **蓄力预警**：原有固定落点圆圈保留，新增随蓄力完成的弧线和渐强底色。预警仍在攻击开始时锁定，移动或闪避离开仍然有效。

不改伤害、掉落、技能倍率或存档格式，不改成自动施法。位置变化本身会影响范围命中和走位，未宣称战斗已全面平衡。

- npm audit 0 个已知告警。
- 新增 `combat_targeting_e2e.py`：真实 Tab 和点击锁定、显示名字与保持目标、怪物堆叠位置校正、固定蓄力位置、死亡重选、尸体不可点击与下边界检查通过。群怪、死亡和蓄力采用明确的状态夹具，不冒充全流程真实游玩。

## 边界与后续

软性分散不是完整物理碰撞或寻路，在边墙/多个固定对象挤压时不保证全体始终满足最小间距。当前敌人数以地表 1–2、地牢 1–3 为主，未做百怪压力测试。保持独立战斗场景，不是无缝战斗。

下一优先级建议：可读的敌方行动状态、战斗结算摘要、遭遇前后反馈；随后返回任务追踪和支线指路，避免不断增加按键却忽视正常探索路线。各轮独立分支累积前轮修改，合并 main 才会触发既有 Pages 发布。
