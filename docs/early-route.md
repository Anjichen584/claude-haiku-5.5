# 新手路线验证与修复

## 阶段 1：章节二营地补给

固定新手狼三组五只的掉落不包含裂隙碎片；第一章奖励 1 个，第二章需要 3 个。玩家虽然能另找野怪刷材料，但新手指引路线没有可靠供给。

在第二章进行中、第一章已完成、营地已发现且玩家距中心不超过 1.5 格时，首次补给将碎片**补足到 3 个**，另发一瓶治疗药剂。已有足量碎片不再增加。先设置一次性领取标记，再同步收集、结算任务并自动存档；写盘失败沿用现有提示/K 重试机制。领取标记保留在现有 v1 flags 中，不改地图、坐标或存档版本。旧档未完成第二章时可以返营领取；已完成者不补发，不能反复领取。

验证：516 项测试 / 44 文件；TypeScript 和单文件构建通过。`scripts/e2e/early_route_e2e.py` 通过：新档真实 WASD 步行、J/H/空格战斗三场、五只狼、前两章、营地补给、Q 跟踪队长支线、交谈结算、刷新继续后物品/金币不变，134.4 秒，无 pageerror。脚本只读取场景状态决定输入，不写玩家、世界或任务状态，不传送、不注入血量/掉落。这仅验证开局路线，不代表全流程平衡或所有设备性能。
