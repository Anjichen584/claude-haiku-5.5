# 存档备份、迁移与操作帮助

## 入口

左下角 **存档 / 帮助** 打开设置面板，提供“声音 / 存档 / 操作帮助”三页。原右下角“♫ 声音设置”仍可直达声音页。面板打开时暂停游戏更新；关闭后键盘焦点交回画布，避免 Enter 再次激活设置按钮。

操作帮助说明移动、攻击、闪避、技能学习、药剂、任务追踪、装备、精英讨伐、地牢及存档操作。当前仍以键盘/鼠标为主，并非完整触屏支持。

## 导出与换设备

1. 在地表或地牢按 K，确认保存成功。
2. 打开存档页，点击 **导出最近存档**，下载 JSON 文件。
3. 将文件自行传到另一设备，在该设备的游戏标题界面打开存档页，选择文件。
4. 核对等级、金币、场景、已完成任务数与保存时间，点击 **确认导入并替换**。
5. 关闭面板，选择“继续”。

**不是云存档。** 文件读取和下载都在浏览器本地完成，没有上传接口或账号同步。音量设置不包含在游戏存档中，仍由各浏览器独立保存。

## 三种导出来源

- **最近存档**：最近成功写入的完整检查点。如果主存档损坏而上一备份有效，导出恢复副本，并提示进度可能回退。
- **上一备份**：现有自动备份槽位，正常保存会滚动更新。
- **导入前备份**：最近一次成功保留的导入前有效存档。后续普通自动保存不覆盖它；下一次导入可能更新它。重要历史版本仍需自行下载保管。

不会把实时会话直接导出：进行中的战斗可能已有临时击杀奖励但尚未完整结算，导出这种状态会破坏检查点一致性。下载的是已经保存的状态，因此可能不包含未保存进度。

## 覆盖保护

- 仅标题界面允许导入。地表脱战且结束对话、抉择、交易后，可用 **保存并返回标题**；地牢非交易状态也可使用。
- 独立战斗场景、地表交战、对话和交易期间不能通过此按钮强行返回标题。
- 保存失败时留在当前场景，不丢弃内存进度。
- 选择文件先做 JSON、版本、游戏结构和当前任务定义的重建检查；最大 2 MB，按 UTF-8 字节计算。
- 校验与预览不写存档，必须再确认；取消、关闭或切页会取消尚未确认的导入。
- 预览后如发现现有主存档或上一备份发生变化，会拒绝覆盖并要求重新选文件。这是覆盖前检查，不是跨标签页数据库事务；不建议同时开多个游戏标签页操作存档。
- 有有效旧存档时，先写独立的导入前备份，再执行原有主备写入流程；备份失败或存储额度不足时拒绝替换主存档。
- 无效/过大/不兼容文件不会导入。用户文件名和摘要使用纯文本显示，不当作 HTML 执行。

## 验证

`tests/save-transfer.test.ts` 覆盖预览不写入、UTF-8 限制、错误文件、读写失败、预览后变化、旧档备份持久性、新浏览器导入和损坏主档恢复。

`scripts/e2e/save_tools_e2e.py` 使用真实下载与文件选择，检查取消、存储额度故障、导入确认、旧档下载、导入后继续和普通保存不破坏导入前备份。输入文件中的金币和标记是明确测试夹具，不属于正常游戏奖励。

`scripts/e2e/audio_surface_e2e.py` 额外检查地图战斗中不能通过存档面板逃离战斗。
