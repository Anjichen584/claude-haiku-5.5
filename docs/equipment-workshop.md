# 营地装备工坊

## 使用

在起始营地行旅商人（4,4）五格内，脱战并结束对话、交易或奖励选择，点击左下角「存档 / 帮助」→「工坊」。C 装备面板也提供工坊入口。远处只能查看装备与换装对比；地牢和训练场不能操作。

- **对比与换装**：预览含词条、精炼和套装的完整战斗属性计算，界面展示攻击、防御、生命、魔力、暴击、移速和吸血；预览不会自动穿戴。
- **精炼 +0～+5**：每级武器 +2 攻击、护甲 +1 防御、饰品 +4 生命上限与 +3 魔力上限。升上限不会免费治疗，降上限会裁剪当前资源。
- **重铸**：选择现有的非隐藏词条；其他词条和隐藏词条不变。替换池只用已接入战斗的属性，但结果可能更低或相同。每款装备最多 200 次。
- **分解**：每次确认只消耗背包副本一件，不处理身上穿戴的装备。普通/优秀/稀有/史诗/传说/裂隙品质分别获得 1/2/3/4/5/6 裂隙碎片。

精炼当前等级 r 的费用为 `80*(r+1)` 金币与 `r+2` 碎片；已重铸 n 次后的费用为 `60+20*n` 金币与 `2+floor(n/5)` 碎片。碎片也可能用于任务。所有操作先确认，切换标签/装备或关闭面板会取消待确认操作；执行前复查位置、状态和资源。

## 边界与存档

这是**按物品类型共享的图谱**，不是每件装备独立实例。同款所有副本共享精炼与重铸；卖掉或分解最后一件后记录仍保留，未来再获得同款会继承。出售价格仍按基础物品计算。

图谱是旧存档可缺省的 `player.crafting` 字段，重铸历史可确定性重放。保存/恢复使用独立副本，并校验物品、等级、次数和非隐藏词条索引。无图谱的旧存档、原始词条算法不变。操作后自动保存；保存失败会明确提示当前进度仅在页面内，勿刷新，应回游戏按 K 重试。这不是跨标签页事务或云存档。

## 验证

- 单元测试：费用、上限、距离、拥有权、材料不足、分解保护、隐藏词条、确定性重放、旧存档、快照隔离、换装不变更状态、资源上限与坏存档拒绝。
- `scripts/e2e/workshop_e2e.py`：生产构建中的确认/取消、换装、精炼、重铸、分解、执行时位置变化、刷新继续、实际地表战斗 profile 与预览一致。金币/材料使用显式测试夹具，不代表正常游玩收益。
- 继续回归存档迁移、无缝地表战斗/音频、地牢检查点和离线单文件。

尚未实现：独立装备实例迁移、地牢与地表战斗范式统一、全面经济/长线平衡、完整移动端适配。
