# 主题远征：预算、连续消耗与主线衔接观察

## 本轮结论

**整套未精炼灰烬装备并不等于刚完成第二章的低阶装备。** 上轮采样预设了火球、魔力护盾和陷阱；后两项带前置技能和较高技能点成本，不能当作 Lv.4/5 自然可学的技能组合。本轮保留它们作为强配装功能夹具，但不再用其结果推断自然成长难度。

新的有限预算对照显示：低阶装备硬扛会失败，读预警并闪避则可通关。暂不把失败直接归因于敌人数值，也不据此削弱普通 Boss 或改奖励。大厅准备提示改为当前装备、技能栏与治疗药剂检查，不再只推荐等级；这是只读建议，不是新门槛或通关保证。

## 可复现夹具与范围

脚本：`scripts/e2e/forge_loadout_matrix.py`。

- 仅计前两章任务奖励 **800 经验 / 320 金币**，等级 **Lv.4**、3 个技能点。不额外加入击杀、支线、出售和声望折扣收益，故是保守预算夹具，不是假称真实跑图所得的完整财产。
- 使用商店实际购买函数，按全价倍率 1 购买；装备从背包通过装备规则穿戴，无精炼。火球通过技能树合法学习：1 点、无前置，余 2 点。无护盾、无陷阱。
- 低阶：铁剑 40 + 皮帽 25 + 皮衣 35 = **100 金币**；另购 4 治疗 / 4 回魔 = 132，余 **88 金币**。加新档原有药剂，共 6 治疗 / 5 回魔。
- 混搭：荒原猎刃 180 + 皮帽 25 + 皮衣 35 = **240 金币**；另购 2 治疗 / 2 回魔 = 66，余 **14 金币**。共 4 治疗 / 3 回魔。
- 每种配装的每条路线从独立满资源夹具开始。**同一路线第二次尝试延续第一次的生命、魔力、药剂、经验、货币和真实共享药剂冷却，不补满、不重置。** 胜败后都按实际规则保留/恢复生命。
- 每场真实 E/J/数字键/地图输入，按提示顺序操作阀门，不注入伤害、移动或结算。J 为自动接近挥砍，火球按冷却反复尝试。治疗低于 65% 才尝试，药剂效果与冷却照常。
- 无闪避组每配装/路线连续 2 次，共 8 次。闪避组也各连续 2 次，共 8 次；仅额外读取敌人预警，在危险时真实按 A + Space，不加无敌时间。另做过 4 次单轮先导，未混入下面连续组。
- 沙箱 Phaser AUTO Canvas 回退，无游戏加速。墙钟受机器与同时运行的测试影响，不是标准化性能测量；时间不宜跨机器精确比较。

## 实际结果

无闪避连续组：**0/8 通关**；多数在 Boss 失败，带伤连续第二次的支库路线也可能在精英支库失败。每次消耗 1 治疗、0 回魔，奖励为 0，按全价替换药剂成本 **−18 金币/次**。这是固定硬扛策略的结果，不等于所有低阶玩家必败。

闪避连续组：**8/8 通关**。下表为每个组合的连续第 1 / 第 2 次，均未补满资源：

| 配装 / 普通路线 | 全路线墙钟 | 治疗消耗 | 回魔消耗 | 剩余生命 | 金币增量减已用药剂替换价 |
|---|---|---|---|---|---|
| 铁剑皮甲 / 直接 | 35.17 / 35.78s | 2 / 2 | 0 / 0 | 100 / 100 | +84 / +84 |
| 铁剑皮甲 / 支库 | 40.19 / 40.47s | 1 / 2 | 0 / 0 | 76 / 98 | +162 / +144 |
| 猎刃皮甲 / 直接 | 30.86 / 29.40s | 1 / 2 | 0 / 0 | 76 / 62 | +102 / +84 |
| 猎刃皮甲 / 支库 | 36.79 / 34.14s | 2 / 1 | 0 / 0 | 100 / 76 | +144 / +162 |

奖励验证：直接每次 **240 经验 / 120 金币 / 3 余烬**；支库每次 **360 / 180 / 5**；战中没有额外击杀奖励。金币列用治疗 18、回魔 15 的实际基础购买价计算，但**未扣初始装备成本、升级/精炼成本、路途成本、时间机会成本**，也没有模拟实际补货，不能称为完整净利润。持续使用火球可由自然回魔支撑，不代表所有技能组合都无需回魔药。

两次后混搭两路线都只剩 1 瓶治疗，后续循环需要补货。支库在这些有限样本中仍有较高收益/药剂成本比，不能宣称两条路线经济完全平衡；只有两次连续成功，不足以证明长期经济或最佳刷装策略。

### 复跑

在仓库根目录安装现有依赖与 Playwright Chromium，启动生产预览后：

```sh
GAME_URL=http://localhost:5173 FORGE_MATRIX_OUTPUT=/tmp/no-dodge.json python scripts/e2e/forge_loadout_matrix.py
GAME_URL=http://localhost:5173 FORGE_MATRIX_DODGE=1 FORGE_MATRIX_OUTPUT=/tmp/dodge.json python scripts/e2e/forge_loadout_matrix.py
```

默认每配装/路线连续两次，`FORGE_MATRIX_ATTEMPTS` 可调整次数；结果包括每室耗时、每轮前后资源、胜败、奖励、药剂替换成本。死亡是观察结果，不把它改成“测试通过即通关”。脚本会断言页面无异常、战中无多余收益和结算精确。完整矩阵属人工分析复跑，不放进每次 CI 的快速功能门禁；档案馆 E2E 已加入 CI。
