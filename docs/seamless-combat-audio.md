# 地表无缝战斗与声音扩展

## 本轮范围

地表遭遇改为原地图即时战斗，不再因接近刷新点进入 TestRoomScene。地牢房间和 T 试炼仍使用原独立战斗场景；这不是全地图、全地牢一次性重写，也不是回合制。

### 操作

- WASD：移动。J：按住挥砍，没有方向输入时会靠近附近敌人并自动朝向目标。
- Space：闪避，消耗耐力并获得短暂无敌；有方向输入时按移动方向闪避。
- Z：开关原地自动攻击；不会自动寻路跑图。
- 1–4 / 点击技能槽：释放已装配主动技能。G：学习和装配；沿用原技能、魔力、冷却和组合技系统。
- H / M：治疗 / 魔力药剂。E：互动。K：手动存档。
- 右下角“声音设置”：总音量、背景音乐、音效和静音。打开时暂停场景更新。

### 战斗与成长

- 多组怪物同时在地图上活动；普通攻击能击中前方多个敌人。
- 敌人警戒、追击、固定位置攻击预警、受击硬直、脱战归位；走出预警圈或闪避可躲开伤害。
- NPC、地点与起始营地保留安全范围。离开敌人出生点过远会脱战。
- 复用已有 CombatRuntime：技能伤害、持续伤害、控制、生命偷取、护盾、装备与套装奖励等继续生效。
- 新增独立确定性游荡怪群层，2–3 只一组；不移动原有刷新点、不改原击败键，起始 42 格范围内不添加额外怪群。
- 为控制更新负担，仅激活玩家附近的怪群；卸载后未击败成员恢复初始状态，已击败成员保持死亡。
- 击杀即时给经验、金币、掉落和任务进度，显示飘字、血条、拾取提示，无逐场结算弹窗。
- 地表倒下会被救回起始安全营地，恢复一半最大生命；不扣金币，已结算的击杀和掉落保留。

### 存档兼容与边界

继续使用 v1 存档，不重置旧角色。旧版整组 defeated 键照常识别。新规则用 `surface-member:<spawn>:<slot>` 记录未清空怪群中的个别击杀；整组清空后合并为原怪群键。成员标记、金币、物品和任务状态在同一份存档中保存，避免打到一半刷新后重复领取已保存的奖励。

未死亡怪物的具体位置、剩余 HP、临时技能冷却不跨页面保存；回到地图可能恢复这些未完成战斗。浏览器拒绝写入时仍显示现有保存失败提示，K 可重试；失败后关闭页面可能丢失未保存进度。

### 声音

- 使用 Web Audio 程序合成的原创短循环配乐，不含第三方商业音乐、外部音频请求或运行时 AI。
- 标题、探索、交战、地牢、Boss 五种音乐模式，包含旋律、和声、低音、战斗节奏与轻环境噪声；天气影响探索环境音色。
- 挥砍、命中、受伤、闪避、技能、拾取、升级、保存、倒下与部分 UI 操作有合成音效。
- 一个全局 AudioContext 与一个调度器跨场景复用，后台自动暂停，不反复叠加独立播放器。
- 第一次点击/按键后解锁播放，遵守浏览器自动播放限制；不支持音频时不影响游戏。
- 音量设置使用独立 `rift-audio-v1` localStorage 键，不随新游戏清空；静音和三类音量会保存。
- 这是一版程序合成音轨，不声称已制作长篇录音配乐或真人乐器素材。

## 验证入口

- `npm test`：含无缝战斗、部分击杀存读档、幂等奖励、音频设置与独立怪群生成测试。
- `scripts/e2e/early_route_e2e.py --snow`：真实 WASD / J / 药剂 / 闪避，检查前三章路线，不注入伤害、HP、位置或任务进度。
- `scripts/e2e/audio_surface_e2e.py`：明确使用位置、已学技能和死亡状态夹具；键盘施法、闪避、击杀、存读档；检查音频分析器有输出、实际静音、设置持久化。
- `scripts/e2e/story_patrols_e2e.py`：剧情任务状态夹具，检查已加载巡逻队按任务状态出现/消失，无场景切换。
- 地牢存档回归与离线单文件测试继续保留。

## 仍待扩展

独立装备实例、更多区域专属机制、地牢内无缝战斗、触屏虚拟摇杆、更丰富的编曲及长时间难度平衡不在本次完成范围。当前仍为键盘/鼠标优先的可玩原型，不承诺已经验证 80–100 小时内容。
